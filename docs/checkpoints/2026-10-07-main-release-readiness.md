# Main 发布候选检查

## 范围

候选从 `beta` 的 `4e9fd5b` 创建
`beta-fix/release-checks-20261007`。前序小说、漫画、短剧功能已在 beta；本阶段处理实际远端 CI 暴露的发布阻碍。部署目标是单 API 的 Docker 自部署，不发布桌面安装包。

## 诊断与修复

- 原 CI `37584307471` 的应用构建通过，但 ESLint 和测试任务失败。5 处 React
  effect 依赖改为完整、稳定的依赖，避免草稿和任务投影使用过期状态。
- 工作区依赖采用注入副本，干净安装后的 shared 构建没有同步新文件。pnpm
  10.6.0 的隔离工作区复现后，通过 `syncInjectedDepsAfterScripts: [build]`
  修复；原取消执行测试能够加载共享契约并通过。
- 短剧视频测试的自定义加载器按当前源模块目录递归解析和缓存依赖，加载真实事实契约，不用替身掩盖缺失模块。
- 本次候选修改过的文件按既有 Prettier 配置整理。固定 1,678 个 main 原有、在原 beta 仍为相同 Git
  blob 的历史格式债务；新内容必须通过真实格式检查。通过对旧内容运行同一格式化器再比较，确认大批源码差异仅来自格式整理。
- 审计实际报告 12 项漏洞，原 job 因允许步骤失败仍显示成功。安全补丁升级后，生产依赖 0 漏洞；全量报告仅余开发依赖 braces 的上游无补丁告警。CI 将生产依赖审计设为阻断检查，保留全量报告。

## 本机阶段验证

- shared 与服务端 TypeScript 构建成功。
- 最终依赖下客户端类型检查通过，完整客户端测试 287 通过、1 项桌面专属测试跳过。
- 客户端 ESLint 全量通过；格式门禁边界测试 6/6。
- 短剧视频生命周期 16 与台本版本保护 5 通过，包含真实 SQLite 并发提交检查。
- Shared 注入依赖在临时工作区先失败后通过，修复不要求改变锁文件格式。
- Sharp 0.35.5 / libvips 8.18.7 的真实内存 PNG 编解码通过。
- 最终生产依赖审计退出 0；无修改作品数据库或真实付费模型调用。

完整服务端快测、客户端合同测试、完整应用构建和 PostgreSQL Docker 烟测由 beta
CI 执行。只有候选对应的 CI 和 Docker 验证通过后才允许快进 main；不能用本机专项测试代替这些集成门禁。UI 交互验收按项目规则留给用户。

## 保留边界

- `braces@3.0.3`
  的 GHSA-vfj7-8cjw-p6xm 无上游修复，调用来源仅为客户端构建工具；未发现用户输入进入相关模式解析。API 镜像仍可能带有该包文件，不能据此宣称镜像全部依赖零漏洞。
- 格式门禁通过不代表历史格式债务已经清零。
- 未验证真实付费模型的内容质量、费用和角色视觉一致性。
