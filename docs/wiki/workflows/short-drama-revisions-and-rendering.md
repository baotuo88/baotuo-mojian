# 短剧台本版本与成片交付

## 背景

短剧制作包含人工台本、AI 分镜、外部媒体任务和本地合成。这些步骤耗时不同，可能跨越人工修改和服务重启。系统需要保证用户看到的是同一份台本对应的制作结果，同时保留历史成果与供应商任务编号。

## 决策

台本修订是制作链的一致性边界。编辑、生成和修复统一提交；媒体不可变存储；最终成片保存完整时间线快照。AI 负责剧情理解和事实整理，确定性代码负责版本、权限边界、资源限制与媒体拼接。

## 台本与事实

- 人工编辑带预期版本；AI 使用请求前的版本。发生冲突保留人工稿并返回可恢复提示。
- 有实际变化的保存事务内保留前后历史稿，清除旧审校，将分镜标为过期。重复保存不制造新修订。
- 标题或时长修改不应清空事实。正文修改会使本集旧事实过期；AI 生成/修复返回当前整集完整事实快照，人工稿则标待整理。
- 后续集调用 AI 前自动整理前序待更新的事实，整理失败要显式处理。晚到的整理结果不得写回新稿。
- 当前上下文只使用有效前序事实，不引用未来集数。此规则影响短剧台本、修复、审校和分镜，不涉及小说事实账本。

## 媒体与历史

分镜版本和来源台本版本共同标识制作依据。首帧、配音、视频的开始与写回都核验该依据。首帧文件使用唯一文件名，历史地址解析到原始字节；写回失败不能先把文件覆盖。

视频提交结果不明不能自动重发。台本变更期间收到供应商任务编号，仍要保留供费用核对，但归为历史素材。失败的配音保留上一份音频；服务重启只释放中断状态，不自动产生新的供应商费用。

## 成片

- 用户完成当前全部镜头视频后，可合成竖屏 MP4。合成不调用 AI，也不补造缺失镜头。
- 输出为 720×1280、30 fps、H.264/AAC；镜头有配音时按对白时间线替换该镜头原声，无配音则保留原声；字幕烧录在画面中。
- 任务持久保存状态、进度和时间线快照。保存成片前在台本锁内重查全部素材；变化则要求重新合成，已产生的文件保留为历史。
- 成片列表以完整快照判断当前性；仅比较台本与分镜编号不够，同一分镜重做配音/视频也会过期。
- 取消只终止本地合成，保留源素材。重启后遗留任务显示中断，可手动重试。

## 部署与资源

当前只支持单 API 实例。一个实例最多执行一个合成任务，队列和素材时长、数量、下载大小、输出大小、磁盘空间、CPU 线程及超时都有上限。扩容前必须引入全局工作租约，不能让多个实例相互恢复遗留任务。

FFmpeg 只处理已下载的本地文件，不允许输入内部网络地址或播放列表。远程媒体逐次验证公网地址及重定向、连接固定解析后的 IP；本地媒体做真实路径校验。合成临时目录与用户素材目录分开，清理不涉及用户数据。

## 诊断顺序

1. 先确认台本版本、分镜来源版本和状态，避免对旧素材反复重试。
2. 查供应商任务状态，区分提交结果未知、视频生成中与可下载视频。
3. 查成片失败原因：缺素材、过期链接、下载限制、解码失败、超时或磁盘不足。
4. 查成片快照是否对应当前素材；成功的历史文件可以留存，不应误显示为当前成片。
5. 部署前在独立数据库执行实际迁移 SQL；`db push` 通过不代表迁移链有效。独立 FFmpeg 小样验证时长、音轨、字幕，不能只断言 HTTP 200。
