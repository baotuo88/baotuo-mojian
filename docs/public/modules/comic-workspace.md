# 漫画工作台

漫画工作台帮助你将小说或原创故事改编成漫画。可以先完成一话，确认角色与画面效果，再继续连载。

## 从已有小说开始

1. 打开漫画工作台，点击「新建项目」。
2. 选择「我的小说」，搜索并选中需要改编的小说。项目标题可以沿用小说标题。
3. 选择漫画形态和画风，创建项目。
4. 按「从故事到第一话漫画」中的指引准备故事资料、第一话大纲和分镜。
5. 在角色页准备角色设计稿。
6. 打开格子图，确认生成范围和图片服务，生成第一话图片。
7. 查看条带阅读效果，调整需要修改的格子，再到导出页下载。

也可以选择原创灵感或粘贴文本作为故事来源。建议从角色和剧情比较稳定的章节开始，减少后续返工。

## 图片生成与角色一致性

角色设计稿会作为后续格子图的参考。生图前可以查看提示、参考素材和模型参数，并对本次生成作临时调整。

项目顶部可以选择配置好的图片服务。图片生成会使用服务额度；无法可靠估算价格时，请以服务平台的实际账单为准。

如果角色效果不稳定，优先检查角色设计稿、外貌描述和参考图。修改单格画面脚本后，需要重新生图才能在图片中体现修改。

## 批量生成、停止与继续

「生成未完成的格子」会保留成功图片，只处理需要生成的部分。批量任务开始后可以离开页面；重新打开同一话可以查看保存的进度。

- 个别格子失败：使用重试入口补齐失败图片。
- 执行中断：确认后继续未完成图片。
- 希望停止：点击「停止后续生成」。已经发送的图片请求可能仍会产生费用。
- 停止后继续：从同一话的进度区确认继续，保留完成的图片。

需要修改某一格时，可以打开格子详情调整画面脚本，或使用重抽入口重新生成该格。

## 完整导出与下载记录

导出页提供「完整长图」和「分段图片」。全部格子图片完成后才能导出；缺失画面会提示具体格数，并提供返回补图的入口。

分段图片适合按顺序上传到发布平台。导出完成后，每张图片都有下载链接，下载记录保留在项目中，可以稍后返回下载。

导出前请检查整话的画面连续性和对白效果。漫画生图包含对白，普通导出无需再叠加一层文字。
