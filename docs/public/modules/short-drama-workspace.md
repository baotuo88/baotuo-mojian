# 短剧工作台

短剧工作台可从小说、原创灵感或导入文本开始，把故事整理成分集台本、分镜、关键帧、对白配音和视频镜头。小说改编是衍生制作，原小说仍在小说工作台维护。

## 推荐流程

1. 在短剧入口创建项目，选择素材来源和目标集数。
2. 整理素材并生成策略，让 AI 提炼人物冲突、开场钩子和每集悬念。
3. 按“下一步”生成分集大纲、台本，检查并修复质量问题。分集会从尚未规划的范围继续，已有台本保留。
4. 生成分镜，在角色页准备设计稿和声线。
5. 在“设置 → 媒体通道”添加视频、配音服务；关键帧使用支持生图的模型配置。
6. 在项目中执行整集首帧、视频或配音任务，核对镜头结果。
7. 导出台本资料、单集 SRT 字幕或剪辑草稿，交给剪辑工具继续制作。

可先完成一集样片再扩展。无需先配置视频通道才能整理素材或写台本，台本资料也可以独立导出。

## 暂停、中断与继续

- 制作进度会自动刷新。暂停会让正在处理的镜头结束，再停止后续镜头；完成的结果会保留。
- 服务重启后的任务显示为待继续，需要确认后才继续制作，恢复时沿用原任务的生成通道和参考图选项。
- 确认继续会跳过已完成镜头。供应商可能对中断时的请求计费，请先核对通道中的任务和账单。
- 视频提交结果待确认时，必须先核对供应商，再决定是否重新提交。重新提交可能再次计费。
- 更换分镜后，应为当前分镜新建任务，旧任务不会继续生成旧版镜头。
- 页面中的费用是按配置单价估算的制作记录；未配置单价不代表免费，实际账单以供应商为准。

## 资料与成片的区别

整集视频任务完成表示各镜头已提交给视频服务，视频本身仍可能在排队。分镜视频页展示每个镜头的结果和失败原因。

可导出的内容包括项目 Markdown/JSON、单集 SRT 和剪辑草稿 JSON。剪辑草稿会标出缺失的视频或音频，**不等于完成的 MP4**。成片拼接、混音和统一视频输出需要在后续剪辑流程中完成。

## 保留作品资产

素材整理是项目的首次导入。完成后可查看 AI 补充建议和编辑角色；改编其他素材请创建新项目。重复整理请求不会覆盖角色设计稿或声线设置。
