# 正文与派生资料持久化

本目录拥有章节写入的版本条件，外部通过 `index.ts` 使用。

生成和修复必须传入模型开始处理时的
`expectedContent`，不能在生成结束后读取新稿冒充基线。提交在同一事务中核对正文、备份被替换的非空原稿，再按原稿条件写入生成结果。冲突返回 409，事务回滚，既有正文保留。

原稿备份是章节级快照，只记录实际被替换的正文。恢复时由 snapshots 模块保留其余章节，并重建匹配恢复正文的运行资料；不能把这类备份视为完整资料归档。

派生资料写入必须锁定匹配的章节正文。长时 AI 处理期间不持有数据库事务，返回后的短事务负责校验；局部质量问题与正文版本冲突必须保持独立。
