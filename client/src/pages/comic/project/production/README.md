# 漫画首话工作区边界

- `FirstEpisodeGuide`
  根据已保存的内容源、分话、分镜和图片状态展示下一步。故事规划与画面创作仍调用已有注册 Prompt；前端只解释结构化生产状态。
- `BatchBar` 通过项目批量任务查询恢复本话进度。任务必须有
  `progress.episodeId`，不得将项目最新任务当成本话任务；无法识别所属话数的旧记录不猜测归属。
- `batchProjection`
  负责不可信进度 JSON 的校验、任务选择和计数。任务的真实执行、租约、取消与恢复属于服务端。
- `productionGuide` 只表达产物是否齐备，不判断故事质量、角色重要性或创作意图。
- 外部页面通过 `index.ts` 使用组件。下载与导出记录归属相邻 `export/` 模块。

批量确认绑定本次话数、目标数量和图片服务，提交锁覆盖异步创建及进度重新读取。恢复沿用原任务保存的 provider；页面顶部切换图片服务不能静默改变待恢复任务。

批量执行中允许离开页面；选中话数保存在 URL。`interrupted` 与 `cancelled`
都是可见的继续入口，不自动产生新的图片费用。图片失败局限于相应格子，成功图片保持可用。

回归入口：`comicProduction.test.mjs`，覆盖真实组件动作、同任务恢复轮询、提交互斥、跨话隔离以及完整导出下载链接。UI 验收按项目规则交由用户。
