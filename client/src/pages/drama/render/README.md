# 短剧成片输出界面边界

## 职责

本模块消费后端持久化合成任务，不在浏览器下载全量镜头或执行转码。服务器负责素材验证、时长编排、拼接、配音、字幕以及结果持久化；前端只展示任务、进度和用户可执行的操作。

## 当前规则

- `DramaRenderPanel` 通过 `index.ts` 提供给项目导出页，按分集查询任务。`projection.ts` 用制作模块公开 `model.ts` 统一判定当前分镜。
- 当前分镜的每个镜头都必须有成功且带有效链接的视频，才能创建成片任务。历史镜头、旧提示词、成功但无结果链接的任务均不能填补缺口。
- `queued` / `running` 轮询到终态；切换分集后任务继续由服务器运行。重新进入导出页时从任务列表恢复展示。
- 合成不调用 AI 生成通道，所以不需要供应商费用确认。镜头素材生成仍遵循原有付费确认规则。
- 当前成片的判定同时依赖分集 ID、台本版本和分镜 ID，并尊重后端素材快照有效性 `isCurrent`。同一分镜重新制作音视频后，旧成片也可能成为历史版本。其他版本可下载但必须标注历史，不能作为当前台本完成的依据。
- `succeeded` 必须附带成片链接才显示可下载状态。失败或取消保留记录，重试创建独立任务；有运行任务或读取任务列表失败时禁止重复提交。
- 原始镜头视频和已生成配音由后端按合成策略处理；前端不能假定缺失视频可用静帧替代，也不能仅有台本就宣称成片完成。

## 验证

`client/tests/drama/renderProjection.test.mjs` 覆盖素材缺失、台本与分镜失效、进度范围、任务轮询和缺失下载链接。界面交互验收由用户完成。
